# Documentation Index

## Core research documents
- `RESEARCH_SCOPE.md`  
  Περιγράφει το ακαδημαϊκό scope του project, την ερευνητική κατεύθυνση και τη σύνδεση του forecasting με turbine prognostics / health management (PHM).

- `DATA.md`  
  Τεκμηρίωση του **DaKS / Kassel dataset**, της προέλευσης των δεδομένων, των περιορισμών χρήσης και των βασικών data handling αποφάσεων του project.

- `BASELINE_PROTOCOL.md`  
  Ορίζει το baseline evaluation protocol, τα train / validation / test splits, τις leakage-aware πρακτικές και τα standards σύγκρισης.

- `PHM_ROADMAP.md`  
  Περιγράφει πώς το project μπορεί να επεκταθεί από forecasting σε **prognostics**, **degradation monitoring**, **anomaly awareness** και **health-oriented diagnostics**.

## Repository governance
- `README.md`  
  Γενική επισκόπηση του repository, του pipeline και της τρέχουσας κατάστασης του project.

- `CONTRIBUTING.md`  
  Κανόνες για contribution workflow, issue usage, pull request usage και documentation discipline.

- `CODE_OF_CONDUCT.md`  
  Βασικές αρχές συμπεριφοράς και συνεργασίας.

- `SECURITY.md`  
  Responsible disclosure policy και οδηγίες για αναφορά πιθανών security issues.

- `LOGS.md`  
  Χρονολογική καταγραφή της ερευνητικής προόδου, των σταδίων και των βασικών methodological updates.

## Practical note
Η documentation αυτή υποστηρίζει ένα **reproducible research workflow** με έμφαση σε:
- data integrity,
- methodological correctness,
- leakage prevention,
- baseline comparability,
- και μελλοντική επέκταση προς PHM / digital twin experimentation.
