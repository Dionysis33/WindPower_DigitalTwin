# Graph-Aware Methodological Extensions

The graph-aware stages are methodological extensions to the forecasting-first pipeline. They support graph-readiness checks, graph input packaging, and bounded graph-based forecasting experiments.

## Implemented Graph-Aware Path

The documented graph-aware path includes:

- `NB10`: graph data-interface, split-to-graph contract, and artifact verification
- `NB11`: graph-model input packaging and data object preparation
- `NB12`: first graph-based forecasting baseline
- `NB13`: graph ablation and spatial sensitivity analysis
- `NB14`: controlled graph refinement follow-up

## Interpretation

These stages may be described as graph-aware forecasting evidence and methodology. They should not be presented as validated graph superiority, validated GNN or Graph-Mamba superiority, production graph forecasting, or a completed digital twin graph layer.

Graph outputs do not redefine or replace `data/processed/baseline_metrics.csv`.
