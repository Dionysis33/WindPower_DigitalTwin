# Code of Conduct

## Our Commitment

In the interest of fostering an open, respectful, and academically constructive environment, contributors and participants in this project are expected to treat each other with professionalism and courtesy.

This repository supports research and educational work. Discussion should therefore remain focused, respectful, and evidence-based.

---

## Expected Behavior

Examples of behavior that contribute to a positive environment include:

- being respectful in comments, issues, and discussions,
- giving constructive and specific feedback,
- acknowledging uncertainty where appropriate,
- respecting scientific rigor and reproducibility,
- welcoming good-faith questions and suggestions,
- using clear and professional language.

---

## Unacceptable Behavior

Examples of unacceptable behavior include:

- personal attacks,
- insulting or dismissive language,
- harassment or discrimination,
- deliberately misleading scientific claims,
- hostile behavior in code review or discussion,
- publishing private or sensitive information without permission,
- repeated off-topic disruption.

---

## Scope

This Code of Conduct applies within all project spaces, including:

- GitHub issues,
- pull requests,
- discussions,
- commit messages,
- review comments,
- project-related communication tied to this repository.

---

## Enforcement

Project maintainers may remove, edit, or reject comments, commits, code, issues, or other contributions that do not align with this Code of Conduct.

In serious or repeated cases, contributors may be temporarily or permanently restricted from participating in the project space.

---

## Reporting

If you experience or witness unacceptable behavior, please report it privately to the project maintainer.

Reports should include:

- a short description of the incident,
- where it occurred,
- and any context that helps clarify the situation.

All reports will be reviewed in good faith.

---

## Academic Integrity Note

Because this repository is part of an academic research workflow, participants are also expected to respect:

- fair attribution,
- honest reporting of results,
- reproducible methodology,
- and appropriate citation of external datasets and prior work.

---

## Attribution

This Code of Conduct is inspired by common open-source community standards and adapted for the academic and research-oriented nature of this repository.
